# 🔍 Python Log Analyzer & Error Detective

A menu-driven Python project that analyzes application log files, summarizes severity levels, detects repeated errors, searches logs by keyword, and filters entries by severity or date and time.

## ✨ Features

- **📊 Log Summary:** Counts log entries by severity level (`DEBUG`, `INFO`, `WARNING`, `ERROR`, and `CRITICAL`) and displays the three most common levels.
- **🚨 Error Detective:** Extracts error messages and identifies the three most frequently occurring errors.
- **🔎 Keyword Search:** Searches log entries using case-insensitive and partial keyword matching.
- **⚠️ Severity Filter:** Displays log entries matching a selected severity level, with input validation.
- **🕒 Date & Time Filter:** Displays log entries within a specified start and end timestamp.
- **📋 Interactive Menu:** Provides a simple command-line menu for accessing features and exiting the program.
- **🛡️ Error Handling:** Includes validation for user inputs and handling of malformed log timestamps.

## 🛠️ Technologies Used

- Python 3
- `os` — file path handling
- `collections.Counter` — frequency analysis
- `datetime` — timestamp parsing and comparison

```text
Log Analyzer & Error Detective/

```

- `main.py` — contains the log analysis functions and interactive menu.
- `app.log` — the log file analyzed by the program.
- `README.md` — project documentation.

## ⚙️ Requirements

- Python 3.10 or later recommended.
- An `app.log` file generated by your logging application or another compatible source.
- Log entries should use the following timestamp format:

```text
YYYY-MM-DD HH:MM:SS LEVEL logger_name: message
```

Example:

```text
2026-10-20 08:58:52 WARNING main.py: filename not entered
2026-10-20 08:59:01 ERROR main.py: Failed to open file
2026-10-20 08:59:12 INFO main.py: Application close!
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

Replace `YOUR_REPOSITORY_URL` with your GitHub repository URL.

### 2. Navigate to the project directory

```bash
cd "Log Analyzer & Error Detective"
```

### 3. Configure the log file path

Open `main.py` and ensure the `log_file` variable points to the directory containing your `app.log` file.

### 4. Run the program

```bash
python main.py
```
